# Overview

Nerthus is built around a very powerful, flexible, and extensible core. Its advanced power-user features can help you transform a Nerthus project into a parametric powerhouse.

[Variables](variables.md). Define a variable such as Float, Integer, Choice, Bool, Color, or String. These variables can be bound to different node properties. Variables can be controlled through the UI or the [Command Line Automation](../../automation/cli/command-line-automation.md).

[Expressions](expressions.md). Expressions are modifiers applied to either a property, such as a slider, or to the variable bound to the property. It allows you to make modifications to the incoming value.

[Math Node](math-node.md). The Math node is powerful computational node that let you write your own shapes using scripting. It can consume Variables you declare in the Nerthus UI so you can actually control your script through external controls.

[Binding Variables](../../../ui/interface/property-editor/binding-variables.md). This not a direct feature but a byproduct of [Variables](variables.md). You can expose a specific property from a node, and have it be available just like other Variables and edit your node from the Variable Editor panel.
