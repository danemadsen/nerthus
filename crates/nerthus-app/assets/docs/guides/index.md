# Guides

Use this section when you want practical, task-focused help. Guides are organized around production scenarios, integrations, and real workflows instead of individual interface panels or node reference pages.

If [Using Nerthus](../using/index.md) explains how Nerthus works, Guides explain how to apply Nerthus to a specific production problem.

---

## Start Here

> [!NOTE]
> Use Guides when:
>
> - you are moving a terrain into another application
> - you are solving a workflow, scale, format, or output problem
> - you are building a larger project and need practical production habits
> - you want scenario-based advice rather than node-by-node reference

## Main Areas

### Scenarios

Start with [Scenarios](scenarios/index.md) when the question is about a production situation: large projects, workflow hygiene, mesh output, naming, baking, or common quality issues.

Useful starting points:

- [Workflow](scenarios/workflow/index.md) for graph and output workflow habits
- [Large Projects](scenarios/large-projects/index.md) for splitting and managing heavier work

### Use in DCC Apps

Start with [Universal Instructions](use-in/index.md) when you need to move Nerthus terrain into another tool and are not sure whether you need a mesh, a displacement map, or a landscape.

Use app-specific pages when your target tool matters:

- [Apps](use-in/apps/index.md) for DCC app guidance
- [Engines](use-in/engines/index.md) for game engine-oriented workflows

## Suggested Paths

If you are exporting for the first time, read [Universal Instructions](use-in/index.md) before choosing an app-specific guide.

If something looks wrong after import, start with [Common Issues](scenarios/helpful-info/index.md) and then check the guide for your target app or engine.

If a project is becoming slow or hard to manage, start with [Large Projects](scenarios/large-projects/index.md) and [Workflow](scenarios/workflow/index.md) before changing export settings.
