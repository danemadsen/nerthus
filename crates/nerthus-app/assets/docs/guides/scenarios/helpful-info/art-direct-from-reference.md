# Art Direct a Terrain from Reference to Final Mood

Reference does not help much if it only sits beside the viewport.

It becomes useful when you turn it into terrain choices: silhouette, slope language, erosion character, surface breakup, material zones, color mood, and camera distance. The goal is not to copy every detail. The goal is to decide what the terrain must express, then use Nerthus to build toward that.

> [!TIP]
> Write one sentence for the target terrain before adding detail. For example: "dry folded badlands with broad readable ridges for a mid-distance game vista."

## Translate reference into terrain decisions

Start with the parts the viewer reads first.

The horizon shape informs macro terrain and scale. Slope behavior tells you whether the terrain needs cliffs, shelves, hills, dunes, or valleys. Erosion marks tell you about climate, water history, and flow strength. Rock or soil breakup informs surface nodes and masks. Snow, vegetation, dust, or wetness should become height, slope, deposit, flow, or art-directed masks.

Color mood comes later. It should support the form, not hide it.

## Build in the order the viewer reads

First check the macro shape. Does the silhouette match the reference intent? Then check erosion. Does the terrain history make sense? After that, add surface character, masks, and color. Finish by checking the output from the intended camera or target app.

This order matters because a convincing color pass cannot fix a weak landform. It can only disguise it for a while.

## Use reference to say no

Reference is also a filter. It helps reject detail that is too small for the camera, erosion that belongs to another climate, color that hides the landform, material masks that ignore slope or height, or a strong experiment that weakens the intended mood.

When an idea is interesting but does not serve the reference, make it a variation. Do not let it quietly redirect the main terrain.
