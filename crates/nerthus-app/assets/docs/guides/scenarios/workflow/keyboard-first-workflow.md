# Work Faster with Keyboard-First Navigation

You do not need to memorize every shortcut in Nerthus. A small set of keyboard habits removes most of the repeated mouse hunting: create nodes, rename outputs, suspend the engine, inspect Data View, group work, bypass tests, and manage portals.

## The shortcuts worth learning first

| Task | Shortcut |
| --- | --- |
| Lazy Menu | `F1` |
| Create/search nodes | `TAB` |
| Rename selected node | `F2` |
| Mark for export | `F3` |
| Chain nodes by short code (in the node search) | `m,e2,ss` |
| Suspend/resume engine | `` ` `` |
| Terrain tab in Data View | `Ctrl + F1` |
| Build tab in Data View | `Ctrl + F3` |
| Group selected nodes | `Ctrl + G` |
| Bypass selected node | `B` |
| Manage portals | `P` |
| Navigate to... connected nodes | `,` |

## Where they pay off

When a heavy graph keeps rebuilding, suspend the engine before editing several nodes. When output names are unclear, select the node and press `F2`. When you cannot find what will export, jump to the Build tab in Data View. When a branch may be damaging the result, bypass it with `B`. When wires run across the graph, use portals instead of dragging long connections through the whole terrain.

Typing short codes separated by commas in the node search (**Tab**) makes a chain of nodes at once: `m,e2,ss` makes a Mountain, an ErosionPro and a Sandstone, connected in that order.

These are small habits, but they keep attention on the terrain instead of the interface.
