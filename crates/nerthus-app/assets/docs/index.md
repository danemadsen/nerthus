# Nerthus Documentation

Nerthus is a node-based terrain generator: you build a terrain by connecting nodes in a graph, preview it in the viewport, and build it into heightfields, masks, color maps and meshes for other applications.

- [User Interface](ui/index.md): Learn the layout, panels, and everyday controls so you can navigate and work efficiently.
- [Using Nerthus](using/index.md): Step-by-step workflows and best practices for building terrains from start to finish.
- [Node Reference](reference/index.md): Detailed documentation for every node: what it does, its properties, and usage notes.
- [Guides](guides/index.md): Application-specific guides, techniques, and production scenarios.
- [Developers](developers/index.md): Macros, variables and expressions, and building terrains from the command line.

## Finding Your Way

- The contents on the left list every page; the search box above them looks through all of them.
- Links to other pages open here. The arrows above go back and forward, as do the mouse's back and forward buttons.
- **Show Help for this Node**, in the menu at the top right of the property panel, opens the selected node's page.
- Help › Shortcut Reference lists the keyboard shortcuts.

## Starting Out

If you are new to Nerthus, start with [Introduction](using/getting-started/basics/introduction.md), then read the [User Interface](ui/index.md) overview and [Understanding Erosion](using/understanding-erosion/index.md).
