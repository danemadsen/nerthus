# Node Reference

Use this section when you need lookup material rather than a guided lesson. The reference is organized around Nerthus's node library, with supporting maps and integration-specific reference pages where they are useful.

If you are learning how to build terrains, start in [Using Nerthus](../using/index.md) first. If you already know the node, category, or output you are looking for, this is the faster place to work from.

### Node Families

Use [Nodes](nodes/index.md) when you know the kind of processor you need. Node families group related tools so you can compare options quickly instead of searching one long list.

| Family | Use it for |
| --- | --- |
| [Primitive](nodes/primitive/index.md) | Foundational shapes, gradients, patterns, and noise sources. |
| [Terrain](nodes/terrain/index.md) | Large terrain primitives and landform starters. |
| [Modify](nodes/modify/index.md) | Filtering, remapping, warping, shaping, and cleanup operations. |
| [Surface](nodes/surface/index.md) | Surface breakup, stratification, rocks, sand, terraces, and texture-like terrain detail. |
| [Simulate](nodes/simulate/index.md) | Natural processes such as erosion, snow, water, vegetation, and deposition. |
| [Derive](nodes/derive/index.md) | Masks and data maps derived from terrain, color, flow, slope, or surface structure. |
| [Colorize](nodes/colorize/index.md) | Terrain color, palettes, channel operations, and color processing. |
| [Output](nodes/output/index.md) | Rendering, baking, export, and downstream handoff nodes. |
| [Utility](nodes/utility/index.md) | Graph organization, control flow, routing, masking, and helper logic. |
| [Macro](nodes/macro/index.md) | Your installed custom Macros, shown as reusable nodes in the graph. |
