# Node Map

Use the Node Map as a visual lookup for the node reference. It is most useful when you know the kind of terrain operation you need, but want to compare nearby node families before opening an individual node page.

## How to Use It

Start with the node family, then open the matching node reference page for details, properties and examples.

## Node Families

| Family | Use it for... |
| --- | --- |
| [Primitive](nodes/primitive/index.md) | Simple shapes, gradients, masks, patterns, noises, and reusable graph inputs. |
| [Terrain](nodes/terrain/index.md) | Large terrain bases such as mountains, islands, ridges, dunes, craters, and volcanoes. |
| [Modify](nodes/modify/index.md) | Reshaping, filtering, warping, clamping, sharpening, smoothing, and cleanup. |
| [Surface](nodes/surface/index.md) | Surface character such as terraces, rocks, sand, stones, cracks, and stratified detail. |
| [Simulate](nodes/simulate/index.md) | Natural processes such as erosion, snow, debris, water, trees, and vegetation. |
| [Derive](nodes/derive/index.md) | Masks and supporting maps from height, slope, flow, curvature, normals, color, and surface structure. |
| [Colorize](nodes/colorize/index.md) | Terrain color, channel operations, palettes, and weathered color workflows. |
| [Output](nodes/output/index.md) | Preview, render, bake, export, and production handoff nodes. |
| [Utility](nodes/utility/index.md) | Routing, graph organization, masks, comparisons, variables, and reusable graph logic. |
| [Macro](nodes/macro/index.md) | Your installed custom Macros, shown as reusable nodes in the graph. |
