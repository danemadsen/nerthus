# CLUTer

Coloration in Nerthus is based on CLUTs, or color lookup tables. As 2D heightfields are essentially a grid of numbers ranging from 0.0 (lowest) to 1.0 (highest), CLUTs are represented as gradients which are mapped to those heights.

## When to Use It
Use CLUTer when you want to create color gradients which can be mapped to texture masks for creating color maps.
