# SatelliteMap

Generates terrain color from preset satellite-style palettes with controllable range and processing.

## When to Use It
Use SatelliteMap when you need a fast, realistic base color pass derived from satellite-style palettes. It is strongest early in the color pipeline, where it can establish believable terrain color before you refine, layer, or weather that color with Mixer, HueErosion, or other color nodes.
