# Flow

Generates a modern flow map showing how water or material would travel across the terrain.

## When to Use It
Use Flow when you need a mask of where water would run across the terrain, for rivers, wetness, or vegetation along channels.

## Properties

#### Flow length

Controls how far flow paths are traced across the surface (longer values produce longer streams/flow lines).

#### Flow volume

Controls the amount/strength of flow accumulation used to form the flow map (higher values emphasize major channels).

#### Seed

The randomization pattern or seed for the node's process.
