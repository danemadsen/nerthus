# Macro

Your installed custom Macros appear here as reusable nodes. These entries come from `.macro` packages installed in Nerthus, so the exact list depends on your local Macro library.

Use this family when you want to:

- reuse a packaged graph as a normal node
- find a team, project, or personal Macro by name
- create an instance of a custom tool without opening its source graph

For reference on the native Macro instance node, see [Macro](../utility/macro.md). To define Macro inputs and outputs while authoring a Macro, use [MacroPort](../utility/macro-port.md). For the full creation workflow, see [Building Macros](../../../developers/extensibility/macros/building-macros.md).
