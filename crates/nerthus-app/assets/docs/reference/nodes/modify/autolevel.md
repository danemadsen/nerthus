# Autolevel

AutoLevel is a leveling node that allows you to level your terrain. This node can be useful when you want to stretch your terrain vertically or emphasize certain types of heights. It can also be very useful when working with masks; such as Flow output from the Erosion node, or any other 2D mask that may look too faint.

By default, AutoLevel automatically stretches the heights of the terrain between 0 to 100% height while maintaining the proportions.

This node does not have any properties or controls.

> [!NOTE]
> For more convenient usage, try the Autolevel modifier. See [Using Modifiers](../../../using/managing-graphs/using-modifiers.md).
>
> Or you can try the [Adjust](adjust.md) node which is an easier to use node and provides additional functionality.

## When to Use It
Use Autolevel when terrain values need to be rebalanced so the full height range is usable again before later nodes.
