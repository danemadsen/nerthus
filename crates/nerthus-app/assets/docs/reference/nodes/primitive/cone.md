# Cone

Generates a simple conical gradient that is useful as a primitive shape or mask.

## When to Use It
Use Cone when you need a simple conical gradient that is useful as a primitive shape or mask.

## Properties

#### Scale

Controls the overall size (radius) of the cone.

#### Height

Controls the height (amplitude) of the cone.

#### X

Offsets the cone’s center along the X axis.

#### Y

Offsets the cone’s center along the Y axis.
