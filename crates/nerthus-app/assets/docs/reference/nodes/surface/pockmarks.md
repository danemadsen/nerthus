# Pockmarks

Creates scattered pits, dents, and small impact-like depressions on the surface.

## When to Use It
Use Pockmarks when you need scattered pits, dents, and small impact-like depressions on the surface.

## Properties

### Pockmarks

#### Size

Controls the average diameter of each pockmark. Larger values produce bigger pits, while smaller values create finer surface detail.

#### Scale

Sets the overall scale of the pockmark pattern, affecting how widely pockmarks are distributed across the terrain.

#### Depth

Specifies how deep each pockmark is carved into the surface. Higher values create more pronounced depressions.

#### Density

Adjusts how many pockmarks are scattered across the terrain. Higher values increase the number of pits per area.

#### Multiplier

Scales the intensity or strength of the pockmark effect, amplifying the impact of each depression.

#### Invert

Inverts the effect, turning pockmarks into raised bumps instead of depressions.

#### Seed

Randomization seed for pockmark placement and variation. Changing the seed produces different pockmark patterns.
