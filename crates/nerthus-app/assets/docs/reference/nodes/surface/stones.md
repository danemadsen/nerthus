# Stones

Scatters stones or small rock forms across the surface.

## When to Use It
Use Stones when a surface needs scattered stones or small rocks.

## Properties

### Stones

#### Scale

Controls the overall size of the stones. Higher values produce larger stones, while lower values create finer gravel.

#### Height

Sets the maximum elevation or prominence of the stones above the terrain surface.

#### Density

Adjusts how many stones are scattered across the surface. Higher values increase the number of stones per area.

#### Seed

Randomization seed for stone placement and variation. Changing the seed produces different stone patterns.
