# CraterField

Creates a landscape full of craters.

## When to Use It
Use CraterField when you need a landscape full of craters, such as a moon's surface.

## Properties

### Craterfield

#### Scale

Controls the overall size (radius) of craters in the field.

#### Depth

Controls how deep the craters carve into the terrain.

#### Density

Controls how many craters are generated across the terrain (higher values create more impacts).

#### Seed

The randomization pattern or seed for the node's process.

### Position

#### X

Offsets the craterfield along the X axis.

#### Y

Offsets the craterfield along the Y axis.
