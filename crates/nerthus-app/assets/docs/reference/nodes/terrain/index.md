# Terrain

Terrain nodes create large-scale landforms that can anchor the rest of a graph. Use this family when you want a recognizable base terrain before adding erosion, surface detail, color, or export logic.

Start here when you need to:

- block out mountains, ridges, islands, dunes, craters, or volcanoes
- establish the main silhouette of a terrain quickly
- create a base that will be refined by Simulate, Surface, Modify, or Colorize nodes
- compare landform generators before committing to a graph direction

Useful starting points:

- [Mountain](mountain.md), [MountainRange](mountain-range.md), and [MountainSide](mountain-side.md) for mountainous terrain
- [Canyon](canyon.md), [Ridge](ridge.md), [Rugged](rugged.md), and [Uplift](uplift.md) for stronger structural landforms
- [DuneSea](dune-sea.md) and [Slump](slump.md) for softer or wind-shaped terrain
- [Crater](crater.md), [CraterField](crater-field.md), [Island](island.md), [Plates](plates.md), and [Volcano](volcano.md) for specific landform types

## In this section

- [Canyon](canyon.md): Canyon is a simple, fast, and detailed canyon primitive. It creates a drainage based river canyon
- [Crater](crater.md): The Crater primitive creates different types of crater shapes
- [CraterField](crater-field.md): Creates a landscape full of craters
- [DuneSea](dune-sea.md): Creates broad fields of dune-like terrain suitable for deserts and wind-shaped landscapes
- [Island](island.md): The Island node lets you draw basic shapes from which entire landmasses can be generated
- [Mountain](mountain.md): Mountain is one of the most versatile primitives in Nerthus
- [MountainRange](mountain-range.md): MountainRange quickly sets up an entire mountain terrain with shapes highly optimized for eroding large-scale landscapes
- [MountainSide](mountain-side.md): Generates a single mountain slope or mountainside formation
- [Plates](plates.md): Plates primitive is based on a Perlin core with flat plate-like formations created in between larger Perlin-esque shapes
- [Ridge](ridge.md): Ridge creates a rugged ridgeline with multiple fractures and rock shearing
- [Rugged](rugged.md): Rugged is a very powerful primitive node that creates a strong, rocky surface for any terrain while preserving overall shape
- [Slump](slump.md): Slump is a simple primitive that creates relative smooth hills with slumped (collapsed) areas. It is very useful for creating large landscapes
- [Uplift](uplift.md): Creates tectonic-style uplift by raising and shaping large terrain masses
- [Volcano](volcano.md): Generates a volcanic landform with a central cone and crater structure
