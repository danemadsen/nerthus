# Accumulator

One of the common ways a graph gets cluttered with overlapping connections is when multiple Snow, Lake, or Debris nodes are used and their respective masks need to be combined for further use.

The Accumulator node is a special type of standalone Generator node that can collect all such masks for you without creating several connections.

It works for Snow Mask, Snow Depth, Rivers, Water Mask, Water Depth, Shore Mask, Debris Mask, Debris Color, Trees, Tree Dead Zones and Tree Freshwater.

> [!WARNING]
> The Accumulator will only add nodes that have been built. To ensure all required nodes are built, connect the last node you will use for masking with the Accumulator output to the Accumulator Input. This will not affect the Accumulator but will ensure that all appropriate nodes are built.

> [!NOTE]
> This node can work with accumulation-driven data, which makes it a good candidate for erosion, flow, snow, or water-oriented setups.

## When to Use It
Use Accumulator when several nodes in the graph generate the same kind of data map and you want one combined result without wiring every output manually.

## Properties

#### Type

- **SnowMask**: Accumulate all snow as a flat mask.
- **SnowDepth**: Accumulate all Snow Depth at absolute values.
- **Rivers**: Accumulate all rivers.
- **WaterMask**: Accumulate all water as a flat mask.
- **WaterDepth**: Accumulate all Water Depth in absolute values.
- **ShoreMask**: Accumulate all Shore masks.
- **DebrisMask**: Accumulate all DebrisMask (using Max mode)
- **DebrisColor**: Accumulate just the DebrisColor (using Max mode).
- **Trees**: Accumulate all trees generated by Trees and Shrubs nodes.
- **TreeDeadZones**: Accumulate all dead zones in Trees nodes.
- **TreeFreshwater**: Accumulate all fresh water flows from Tree nodes.

#### Restrict to group

Restricts accumulating from other nodes that are in the same Group as the Accumulator node.
