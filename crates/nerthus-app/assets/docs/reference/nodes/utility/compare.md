# Compare

Compare is a low-level utility that helps you compare two Heightfields.

## When to Use It
Use Compare when you need to evaluate two inputs against each other instead of just blending them.

## Properties

#### Mode

#### A/B

Ratio of the terrain to compare.

#### Colorized

Show colorized output to signify the modified terrain.

#### Perpendicular

Switch from Horizontal/Stacked to Perpendicular comparison.

#### Swap

Swap A and B inputs.
