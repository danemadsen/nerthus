# Layers

Combines multiple layers using blend operations in a stacked workflow.

## When to Use It
Use Layers when you want several inputs managed as one stacked blend workflow instead of wiring long chains of combine and mask nodes. It is most useful when the graph needs clearer organization around layered inputs rather than one-off pairwise blending.
