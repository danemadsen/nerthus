# MacroDefinition

MacroDefinition holds the details of a macro: its name, its author and its description. It sits in the graph a macro is made from, and does nothing when built.

## When to Use It
Use MacroDefinition when building a macro, to name it and describe it. See [Building Macros](../../../developers/extensibility/macros/building-macros.md).

## Properties

#### Macro id

The macro's identifier, made from its author and name.

#### Friendly name

The name the macro shows in the toolbox.

#### Author

Who made the macro.

#### Description

What the macro does. It shows in the toolbox's tooltip.
