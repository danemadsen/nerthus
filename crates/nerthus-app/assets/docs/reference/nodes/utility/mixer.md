# Mixer

Mixer allows layer-based manipulation of color textures and contains in-built masking.

## When to Use It
Use Mixer when you need to build a layered terrain color setup from multiple color sources or masks. It is especially useful when height, slope, or custom masks should control where each material appears before the final result is sent downstream to nodes like HueErosion.
