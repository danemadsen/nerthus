# Seamless

Seamless can transform any input terrain or color map into a tileable/repeating pattern.

## When to Use It
Use Seamless when a terrain or color map has to repeat without visible seams.

## Properties

#### Edge

The amount of blending across the opposite edges.

#### Shift X

Shift blending on the X axis.

#### Shift Y

Shift blending on the Y axis.
