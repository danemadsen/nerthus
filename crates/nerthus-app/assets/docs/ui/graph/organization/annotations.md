# Annotations

Notes let you write on the graph: what a branch does, what is left to do, or why a value was chosen. They are saved with the project, listed in the Data View's [Terrain View](../../interface/data-editor/terrain-view.md), and moved with the group they sit in.

## Adding a Note

Right-click an empty part of the graph and choose **Add Note**, or use Graph › **Add Note** (also in the graph toolbar's menu).

## Writing

Select a note and press **F2**, or choose **Edit Note** from its right-click menu, to open the Note Editor: the note's text on the left, and how it reads on the right. Notes are written in Markdown, so `**bold**`, `*italics*`, lists, headings and links all work. Close the editor (or press **Escape**) to keep the text.

## Arranging

- Drag a note to move it, and its bottom-right corner to resize it.
- Double-click a note to switch it between its text and a small note icon, which shows the text as a tooltip. Icon notes keep busy graphs tidy.
- Right-click a note to change its color or delete it.
