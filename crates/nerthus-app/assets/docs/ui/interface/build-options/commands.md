# Commands

The buttons along the bottom of Build Settings launch the build or expose the equivalent command line for automation.

* **Execute Build**: Closes Build Settings and starts Build and Export for the current file, a full-resolution build using the active Build Settings.
* **Copy Command Line**: Copies the command that builds the current file from a terminal: `nerthus-build build "<file>"`. The Data View's **Variables** tab shows the same command with every variable's value (**Show Build Command Line**).

See [Command Line Automation](../../../developers/automation/cli/command-line-automation.md) for more detail on using the command.
