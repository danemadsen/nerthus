# Profiles

The **Profiles** tab lets you save the current Build Settings as a named preset. This is useful when you need different output setups, such as preview, production, or application-specific exports, for the same terrain.

Pick a profile from the list and click **Load** to apply it; **Save** updates the selected profile with the current settings, **Save As...** saves them as a new profile, and **Delete** removes the selected one.

See [Profiles and Batch Builds](../../../using/advanced-topics/command-line-builds/profiles-and-batch-builds.md) for advanced workflows.
