# Export View

The Build tab of the Data View gathers what a build needs without opening [Build Settings](../build-options/index.md).

Its toolbar has:

- **Execute Build** – Build and Export, as Project › Build and Export does.
- **Open current build folder** – the folder the last build wrote to.
- **Build Settings** – the full [Build Settings](../build-options/index.md) window.
- **Build Statistics** – how long each node took and how much memory its cache uses.

Below it are the build's resolution and its destination (with a browse button to pick the folder by hand), then each node marked for export with its ports, file name and format. Change a format or turn a port off here, as in Build Settings' [Nodes](../build-options/nodes.md) tab.
