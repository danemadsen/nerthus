# Data Editor

The Data View (also called the Data Editor) is the panel beside the graph that shows the project as data: its structure, its build, readouts of what is selected, and its variables. The chevron on the graph toolbar opens and closes it; **Ctrl + F1** opens it on the Terrain tab and **Ctrl + F3** on the Build tab. Drag its edge to make it wider or narrower.

Its four tabs hang along the bottom:

- [Terrain View](terrain-view.md): The project's graph tabs, groups, nodes and notes as a tree, with filters
- **Build**: The build's resolution and destination, and the nodes marked for export (see [Export View](export-view.md))
- **Stats**: Readouts of the selected nodes, or of the whole terrain when nothing is selected
- **Vars**: The project's variables (see [Automation View](automation-view.md))

For a workflow-oriented tour of each tab, see [Data View](../../../using/managing-graphs/data-view.md).
