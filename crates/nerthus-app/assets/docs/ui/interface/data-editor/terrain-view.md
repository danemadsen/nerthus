# Terrain View

The Terrain tab of the Data View lists the project as a tree: each graph tab, the groups on it, the nodes in each group from left to right, and the notes. Click a node to select it and go to it in the graph; right-click it for the same menu as in the graph. Most node shortcuts work here too.

## Locked and Underlay Nodes

The two buttons at the top show the node the preview is locked to and the underlay node. Hover over one to see which node it is, or click it to go to that node. See [Lock Preview](../../graph/basic-workflow/lock-preview.md) and [Underlays](../../graph/basic-workflow/underlays.md).

## Filters

The filter menu narrows the tree to the nodes that match, and dims the others in the graph:

- **None** shows everything.
- **Marked for Export**, **Requires Baking**, **Nodes with Errors**, **Heavy Nodes** (the slowest to build), **Orphan Nodes** (feeding nothing), **Bypassed Nodes** and **Has Modifiers** find nodes by what they do or how they are set.
- **Generators**, **Simulations**, **Colorizors**, **Exportable** and **Logic** find nodes by their toolbox family.

See [Data View](../../../using/managing-graphs/data-view.md) for more on each filter.
