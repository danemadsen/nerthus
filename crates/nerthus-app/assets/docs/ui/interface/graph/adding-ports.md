# Adding Ports

Some nodes can take more inputs than they start with: Combine, Mixer, Layers, Bomber, Construction and TextureBaker. When one is selected, a note under its properties says "This node can add additional input ports."

There are two ways to add an input:

- **Add Input**: click the node's **Add Input** command, above its properties. The new input appears on the node, ready to connect.
- **Drop a connection on it**: a node with more than two inputs shows the extra ones gathered into one port when it is small or compact. Drop a connection on that port to choose which input it feeds, or choose **Add new port** to add an input and connect it at once.

Each node has a limit to how many inputs it takes; past it, Add Input adds no more.

> [!TIP]
> To feed a node's mask instead, drop the connection on the gathered port and choose **Add as Mask**, or turn on Options › Node › Always Show Mask Ports.
