# Interface

- [Graph](graph/index.md): Nerthus's advanced graph-based workflow is the key to creating sophisticated terrains
- [Property Editor](property-editor/index.md): Every node exposes a set of properties or settings that you can modify to influence the effect that node has on the terrain
- [Viewport](viewport/index.md): Previewing the terrain in 3D and 2D, its render modes and measurement tools
- [Data Editor](data-editor/index.md): The Data View beside the graph: the project's tree, its build, readouts and variables
- [Menus and Toolbars](menus-and-toolbars/index.md): The main menu and the toolbars around the graph, viewport and properties
- [Navigation](navigation/index.md): Node bookmarks, the Lazy Menu and keyboard shortcuts
- [Options](options/index.md): Nerthus's preferences, page by page
- [Build Settings](build-options/index.md): Resolution, terrain size, exports, regions, profiles, scripts and build commands
