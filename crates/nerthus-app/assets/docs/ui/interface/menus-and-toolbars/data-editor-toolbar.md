# Data Editor Toolbar

Each tab of the [Data View](../data-editor/index.md) has its own toolbar:

- **Terrain**: the locked preview and underlay buttons, and the filter menu. See [Terrain View](../data-editor/terrain-view.md).
- **Build**: Execute Build, Open current build folder, Build Settings and Build Statistics. See [Export View](../data-editor/export-view.md).
- **Stats**: Build Statistics (how long each node took and how much memory its cache uses) and Memory Statistics.
- **Vars**: Create Variable, Toggle Edit Mode, Group by Nodes, Show Build Command Line, Create Connected Nodes and Delete all variables. See [Automation View](../data-editor/automation-view.md).
