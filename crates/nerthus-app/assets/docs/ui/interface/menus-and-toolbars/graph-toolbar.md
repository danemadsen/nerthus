# Graph Toolbar

The Graph Toolbar runs down the right side of the graph. It hosts the tools and menus most used while building a graph:

*   **Data View**: Opens and closes the [Data View](../data-editor/index.md) beside the graph.
*   **Node Bookmarks**: Mark and quickly navigate to specific nodes. See [Node Bookmarks](../navigation/node-bookmarks.md).
*   **Node Commands**: Shortcuts to commonly used node functions: Select upstream, Select downstream, Group / Ungroup, Combine nodes, Convert port to portals and Move to Tab. See [Organizing Graphs](../../graph/organization/index.md).
*   **Bake**: All baking related options. See [Baking Nodes](../../../using/baking-nodes/index.md).
*   **Refresh**: Rebuilds the selected node.

    Right-clicking **Refresh** offers **Refresh all nodes**, which rebuilds every node in the graph.

*   **Mutate**: Mutates the selected node.

    Mutating lets you build different versions of the same terrain by simply randomizing the Seed properties of the selected nodes.

    Right-clicking **Mutate** offers **Mutate all nodes**, which mutates every node in the graph.

* **Suspend Engine**: Lets you toggle the Nerthus engine. While it is suspended, a red outline crawls around the graph. See [Suspending Engine](../../graph/basic-workflow/suspending-engine.md).
* **Graph Commands**: The commands of the Graph menu:
    * **New Graph Tab**: Adds a graph tab.
    * **Add Note**: Adds a note object to graph surface.
    * **Zoom**: **Extents** (all nodes), **Reset Zoom** (the default view) and **Selection** (the selected nodes).
    * **Graph Surface**: **Show Grid**, **Snap to Grid** and **Snap to Items**.

This toolbar streamlines workflow by grouping critical tools in one accessible location, enhancing the user's ability to manage and optimize graph operations efficiently.
