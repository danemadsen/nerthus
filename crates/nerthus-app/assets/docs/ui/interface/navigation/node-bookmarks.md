# Node Bookmarks

Bookmarks mark the nodes you keep coming back to, so you can jump to them from anywhere in a large graph.

- **Bookmark a node**: right-click it and choose **Bookmark**, or select it and choose **Add bookmark** from Graph › Bookmarks or the graph toolbar's bookmarks menu.
- **Go to a bookmark**: choose the node in Graph › Bookmarks (or the toolbar's bookmarks menu). The graph moves to it and selects it.
- **Remove a bookmark**: right-click the node's entry in the bookmarks menu (it reads "Remove?"), then click it; or untick **Bookmark** in the node's menu.

Bookmarks are saved with the project, and adding or removing one can be undone.
