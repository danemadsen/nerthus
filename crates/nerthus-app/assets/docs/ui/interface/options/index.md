# Options

[General](general.md): The **General** tab provides essential application-wide preferences, controlling how Nerthus launches, handles logs, updates and its network connection, and its diagnostic tools. These settings affect global behavior rather than project-specific options.

[Paths](paths.md): The **Paths** tab defines where Nerthus stores and retrieves user data and project files. Properly configuring these paths ensures smooth operation, faster backups, and prevents accidental data loss or corruption.

[Toolbox](toolbox.md): The **Toolbox** tab customizes the appearance, organization, and search behavior of the node toolbox, improving workflow efficiency and navigation within Nerthus’s graph editor.

[Graph](graph.md): The **Graph** tab controls the behavior, snapping, and visibility of certain interface elements within the node graph workspace, allowing customization of layout precision and shortcut handling.

[Node](node.md): The **Node** tab manages the appearance and interaction behavior of nodes in the graph workspace, allowing customization of visual style, connection handling, and data display precision.

[Data View](data-view.md): The **Data View** tab controls the appearance and expansion behavior of the Data View panel, allowing you to choose how icons are displayed and whether the view should auto-expand for easier navigation.

[Build](build.md): The **Build** tab defines the default output location, file formats, and memory handling preferences for builds in Nerthus. These settings apply globally unless overridden in individual project build settings.

[Cache](cache.md): The **Cache** tab manages how Nerthus stores temporary data and autosaves, allowing you to balance memory usage, disk performance, and long-term cleanup.

[Viewport](viewport.md): The **Viewport** tab allows you to configure the visual display settings for Nerthus’s 3D viewport. These options affect how terrains and masks are rendered during editing and previewing.

[Navigation](navigation.md): The **Navigation** tab allows you to customize how you interact with the 3D viewport using your mouse and keyboard. It provides full control over button assignments, sensitivity, and directional preferences.

[Lazy Menu](lazy-menu.md): The **Lazy Menu** tab lets you control the visibility and prominence of key panels and tools in the Lazy Menu interface. This helps declutter the UI or highlight frequently used options for faster access.

[Compute](compute.md): The **Compute** tab allows you to configure which available hardware devices are used for computation, optimizing performance across CPU and GPU resources.

[Experimental](experimental.md): The **Experimental** tab provides access to preview and in-development features of Nerthus. These options are **not final** and may change or be removed in future updates. They can improve performance or alter behavior but may cause instability.
