# Toolbox

The **Toolbox** tab customizes the appearance, organization, and search behavior of the node toolbox, improving workflow efficiency and navigation within Nerthus’s graph editor.

## **Configuration**

Chooses what the toolbox over the graph's left side looks like:

* **Menus:** One button per category (Primitive, Terrain, Modify and so on), each opening a menu of that category's nodes. _(Default)_
* **Toolbox:** A panel of node buttons in columns.

## **Layout**

With **Menus**, defines how the category buttons look:

* **Compact:** Icon buttons, one to a row.
* **Buttons:** Icon buttons, two to a row.
* **Large:** Buttons with the category's name. _(Default)_

Right-clicking the toolbox offers these settings too.

With **Toolbox**, the panel is **Compact** or **Expanded**, and **Left-align labels** lines the node names up on the left.

## **Organization**

With **Menus**, determines how each category's nodes are grouped:

* **Nested by Family:** Organizes nodes under their respective functional families (e.g., Primitives, Erosion).
* **Show All:** Displays all of the category's nodes in a single, flat list.

## **Icons in Toolbox**

* **Show icons in Toolbox:** Toggles the visibility of node icons in the menus for quick identification.

## **Most-Used Nodes**

* **Highlight most-used nodes:** Shows the nodes you use less than average more faintly, so the ones you use most stand out.
* **Pin most-used nodes:** Lists the nodes you use most first.

## **Search Results**

Configures the appearance of search results:

* **Show Family Name:** Displays the node’s family (category) alongside its name in search results.
* **Show Icons:** Displays the node’s icon in search results for faster recognition.

## **Maximum Results**

Limits the number of search results displayed:

* **5 / 10 / 15:** Sets how many nodes appear in the search dropdown. _(Default: 10)_

## **Satellite Maps List Behavior**

* **Show Satellite Maps List as a Single Stack:** Consolidates all SatelliteMap entries into a single stacked entry, reducing clutter in the toolbox. When disabled, all Satellite Maps appear individually.

## **Notes**

* A compact layout is ideal for users who prefer quick scanning of nodes.
* Enabling icons can improve recognition but may take more space in compact views.
* Nested organization is recommended for beginners to avoid overwhelming lists, while advanced users may prefer the flat view for speed.
