# 2D Viewport

The 2D viewport shows a node's output from above, as an image: useful for reading masks, checking tiling, and placing things precisely.

## Docked

Press **F6** (or the toolbar's **Toggle Docked 2D Viewport**) to show the 2D viewport beside the 3D view. It shows what the 3D view shows. Zoom with the mouse wheel, pan with the middle button, and double-click to switch between the whole map and one pixel per pixel.

Its menu picks heights and colors and opens the [measurement tools](measurement-tools.md), shows another of the node's outputs, and saves the image to a file.

## Floating

Press **Ctrl + F6** (or Node › Locked 2D Viewport) to open a 2D view of the selected node in a window of its own, named after the node. It keeps showing that node, whatever else is selected, as builds update it.

**Ctrl + M** opens one for the selected node, or with nothing selected shows or hides the Map Viewer, which follows the preview.
