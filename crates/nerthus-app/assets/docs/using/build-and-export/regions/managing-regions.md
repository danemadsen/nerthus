# Managing Regions

Regions are edited in Build Settings › Regions. Right-click an empty part of the canvas and choose **Add Region** to add one where you clicked, then drag it, or its corners, to set its position and size. **Snap Regions** in the same menu snaps them as you drag.

## Customizing Regions

Each region can be given its own color: right-click the region and pick one under **Set Color**.

## Renaming a Region

To rename a region, right-click it, choose **Rename...**, and type the new name.

## Deleting a Region

To delete a region, right-click it and choose **Delete this Region**.

## Visualizing a Region

To see the terrain behind your regions, save the current node's preview as a reference image: open the region menu (beside the preview resolution in the title bar, or Preview › Regions) and choose **Save Current Node preview**.

## Using a Saved Node Preview

Once saved, the node preview shows behind the regions as a reference image. To show or hide it, right-click the canvas and choose **Show Saved Reference**. **Preview image opacity** in the same menu sets how strongly it shows.
