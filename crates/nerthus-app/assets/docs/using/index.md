# Using Nerthus

This section covers the core workflows used to build terrains in Nerthus. It is designed to help you move from understanding the terrain graph to shaping surfaces, running simulations, preparing builds, and exporting results.

Whether you are learning the fundamentals or refining a production workflow, these guides will help you understand how Nerthus’s main systems fit together.

## In This Section

* [Starter Guide](getting-started/index.md): Learn the core concepts behind terrain creation in Nerthus.
* [Understanding Erosion](understanding-erosion/index.md): Understand the erosion systems that shape believable landforms.
* [Simulations](simulations/index.md): Explore natural process simulations such as snow, debris, and other surface effects.
* [Crafting the Surface](crafting-the-surface/index.md): Shape and refine terrain forms using Nerthus’s terrain tools and nodes.
* [Colorizing and Textures](colorizing-and-textures/index.md): Add colour, masks, and surface detail to support look development and export.
* [Importing Terrains](importing-terrains/index.md): Bring external terrain data into Nerthus for editing, enhancement, or integration.
* [Managing Graphs](managing-graphs/index.md): Organize, scale, and maintain complex terrain graphs more effectively.
* [Baking Nodes](baking-nodes/index.md): Cache and bake parts of your graph for faster iteration and more efficient builds.
* [Build and Export](build-and-export/index.md): Generate final outputs for use in other tools, engines, and production pipelines.

## Suggested Path

If you are new to Nerthus, start with [Starter Guide](getting-started/index.md) and then continue into [Understanding Erosion](understanding-erosion/index.md) and [Crafting the Surface](crafting-the-surface/index.md).

If you are already building terrains, you may want to jump directly to [Managing Graphs](managing-graphs/index.md), [Baking Nodes](baking-nodes/index.md), or [Build and Export](build-and-export/index.md) depending on your workflow.
