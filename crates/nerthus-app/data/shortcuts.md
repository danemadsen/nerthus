## File Commands

#### General Commands

| Command                            |           Shortcut |
| :--------------------------------- | -----------------: |
| New                                |         `Ctrl + N` |
| Open                               |         `Ctrl + O` |
| Open the latest file               | `Ctrl + Shift + O` |
| Save                               |         `Ctrl + S` |
| Save As                            | `Ctrl + Shift + S` |
| Undo                               |         `Ctrl + Z` |
| Redo                               |         `Ctrl + Y` |
| Toggle 2D Viewport                 |               `F6` |
| Floating Viewport for current node |        `Ctrl + F6` |
| Floating Viewport or Map Viewer    |         `Ctrl + M` |
| Suspend/Resume Engine              |            `` ` `` |
| Attempt to cancel preview build    |              `Esc` |
| Build Settings                     |         `Ctrl + B` |
| Build and Export                   | `Ctrl + Shift + B` |
| Options Dialog                     |   `Ctrl + Alt + O` |
| Console                            |              `F12` |

#### Viewport Navigation

Click the viewport first: it keeps the keys until you click elsewhere.

| Command                                    |       Shortcut |
| :----------------------------------------- | -------------: |
| Move forward / left / back / right         | `WASD` or arrows |
| Rotate                                     |        `H` `K` |
| Incline                                    |        `U` `J` |
| Zoom in / out                              |        `O` `L` |
| Move up / down (Can be flipped in options) |        `Q` `E` |
| Center terrain in viewport                 | `Space` `Home` |
